# Day 17 — Write the deployment-story case study

Goal: turn the flagship n8n workflow into a narrative a hiring manager or prospect can read in two minutes. The build is done — now make it *legible*.

Use `templates/case-study-template.md`.

## Draft it
1. Copy the template to `case-study-n8n.md`.
2. **Problem** — the real ops pain this addresses (intake chaos, manual plan-drafting, slow handoffs). Use your marketing-ops background to make it concrete.
3. **What you built** — the intake → Claude → logged → notify flow, in plain language. One diagram or screenshot helps.
4. **What it replaces** — the manual process and roughly how long it took.
5. **How it'd deploy in a real team** — where it slots in, what it'd connect to (their CRM/Sheets/Slack instead of the demo ones).

## Keep it honest
6. Every claim must map to something you actually built or can show. No invented metrics yet (that's tomorrow).
