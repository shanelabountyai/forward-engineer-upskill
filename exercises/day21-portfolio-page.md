# Day 21 — Build the portfolio page *with Claude Design*

Goal: one polished place to point anyone — a hiring manager, a prospect, a LinkedIn connection. Built with Claude Design.

## Gather what it links to
1. List your assets: n8n workflow (+ demo + case study), MCP server (+ demo + case study), the two Skills, your GitHub repo.
2. Have the URLs/files ready before you design.

## Design + build
3. In **Claude Design**, describe the page: "A clean one-page portfolio/landing page for a forward-deployed AI builder. Hero with a one-line positioning statement, a section per build (problem → what it does → demo link), a Skills section, and a contact/LinkedIn link." Iterate on layout and copy.
4. Keep positioning **practitioner-led and stealth** — "I build AI automations and connectors," not "looking for work."

## Publish
5. Export and publish via **GitHub Pages** (push the static files to a repo, enable Pages) or similar. Confirm the live URL loads on mobile too.

## ✅ Proof
A live portfolio URL. Log it in the tracker.

## Why it feeds the work
The single link behind every conversation (JOB + EXPLORE). This is your front door.
