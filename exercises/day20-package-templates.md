# Day 20 — Package reusable templates

Goal: turn the work into IP you own and can reuse across clients/roles. Assets, not just demos.

## Export the n8n workflow
1. In n8n, export the flagship workflow as **JSON** (Download / Copy to clipboard).
2. Save it to the repo as `templates/n8n-ops-workflow.json` with a short note on what to swap (API key, Sheet ID, webhook URL) to redeploy.

## Document your existing Skills as portfolio pieces
3. You already have a **LinkedIn** skill and an **AJO** skill — write a short one-pager each: what it does, who it's for, how it's used. These are reusable assets, treat them like products.

## Bundle it
4. Make a `templates/` index in your repo README listing the workflow JSON, the two Skills, and the case studies — your reusable toolkit.

## Commit
```bash
git add . && git commit -m "Day 20: exported workflow + documented Skills as IP"
```

## ✅ Proof
Exported workflow JSON + documented Skills.

## Why it feeds the work
Productized IP you can reuse (EXPLORE) and point to in interviews (JOB) and your practice (BP).
