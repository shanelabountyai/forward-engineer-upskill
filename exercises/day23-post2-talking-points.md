# Day 23 — Post #2 + talking points

Goal: a second public post and a reusable talking-points sheet you can pull from in any interview or pitch.

## Post #2 — a "lesson learned"
1. Use `templates/build-log-post-template.md`. Topic: building the MCP server (e.g. "what I learned building an AI connector to my own knowledge base").
2. Make it teach something — the MCP concept, the read-vs-write distinction, a gotcha you hit. Teaching reads as expertise.
3. Link the portfolio + repo. Publish.

## Talking-points sheet
4. Create `talking-points.md`. Draft **5 points**, each mapping a build → a business outcome:
   - Build (what you made) → Outcome (hours saved / reliability / capability unlocked) → one line you'd say out loud.
5. Keep them tight enough to say from memory. These answer "tell me about something you built."
